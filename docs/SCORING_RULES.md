# 评分规则

## 总分计算
- 总分为 100 分
- 语言分：50 分
- 仪态分：50 分

## 语言分 (50分)

### A. 语速 (20分)
- 180~260 字/分钟：20分
- 140~179 或 261~300 字/分钟：15分
- 110~139 或 301~340 字/分钟：10分
- 其他：5分

### B. 停顿 (15分)
- 平均停顿时长 0.5~1.5 秒且停顿次数 3~15 次：15分
- 平均停顿时长 0.3~2.0 秒：10分
- 其他：5分

### C. 口头禅 (15分)
- 口头禅次数 ≤ 2 次：15分
- 3~5 次：10分
- 6~8 次：6分
- >8 次：3分

## 仪态分 (50分)

### D. 正视前方比例 (20分)
- ≥0.70：20分
- ≥0.50：15分
- ≥0.30：10分
- 其他：5分

### E. 低头率 (15分)
- <0.10：15分
- <0.20：12分
- <0.35：8分
- 其他：4分

### F. 姿态稳定度 (15分)
- ≥0.80：15分
- ≥0.65：12分
- ≥0.45：8分
- 其他：4分

## 建议生成逻辑

根据实际指标生成 3 条中文建议，优先挑最明显的问题：
- 语速过快或过慢
- 停顿不自然
- 口头禅偏多
- 正视前方比例不足
- 低头率偏高
- 姿态稳定度不足

如果问题不够 3 条，可以补充正向建议或中性建议，但一定返回 3 条。
