# MVP 范围定义

## 做什么

- **单人课堂展示训练**：只支持单人模式，不支持多人训练
- **本地摄像头采集**：使用设备摄像头进行视频采集

**本地麦克风采集**：使用设备麦克风进行音频采集

- **语速统计**：分析演讲者的语速
- **停顿检测**：检测演讲中的停顿次数和时长
- **口头禅统计**：识别并统计口头禅的使用频率
- **视线方向检测**：分析演讲者的视线方向，计算正视前方比例和低头率
- **姿态稳定度分析**：评估演讲者的姿态稳定程度
- **综合评分**：基于各项指标计算综合评分
- **结果页展示**：展示训练结果和详细指标

## 不做什么

1. **多人训练**：不支持多人同时训练
2. **复杂情绪识别**：不进行高级情绪分析
3. **自由大模型问答**：不接入大模型进行自由问答
4. **登录注册**：不实现用户账户系统
5. **云存储**：不支持训练数据的云存储
6. **实时反馈**：训练过程中不提供实时反馈，只在训练结束后提供结果
7. **视频录制**：不保存训练过程的视频
8. **音频转录**：不提供演讲内容的文字转录
9. **多语言支持**：只支持中文
10. **移动设备支持**：优先支持桌面端，不针对移动设备优化
